# AURA Robinhood Chain contracts

`AuraCollection.sol` uses OpenZeppelin Contracts v5 and is designed for Robinhood Mainnet (chain ID `4663`).

The contract does not charge an AURA platform fee. A free mint only requires Robinhood network gas; a priced mint requires the configured mint amount plus network gas.

Before production deployment, compile and test with Solidity 0.8.24, use a multisig treasury, obtain an independent audit, deploy and verify the source on Blockscout, then set `NEXT_PUBLIC_AURA_NFT_CONTRACT` to the verified address.

The website calls `quoteMint(quantity)` before `mintBatch(recipient, tokenURIs)`. Each transaction is capped at 50 NFTs to bound gas usage.

## V2 authorized minting

`AuraCollectionV2.sol` replaces the unrestricted public mint with an EIP-712 authorization+signed authorization generated by the AURA publishing service. The signature binds the payer, recipient, complete URI list, quantity, current price, nonce, deadline, chain ID and contract address. Per-wallet nonces prevent replay, authorizations expire after ten minutes, and the owner can pause minting or rotate the publishing signer.

Compile with `npm run contract:compile:v2`. Before deployment, configure a dedicated `AURA_MINT_AUTHORIZER_PRIVATE_KEY`; do not reuse the public website wallet or expose this key to the browser. Mainnet deployment additionally requires `AURA_V2_DEPLOY_CONFIRM=DEPLOY_AURA_V2_MAINNET` and is performed with `npm run contract:deploy:v2` only after review and audit.
